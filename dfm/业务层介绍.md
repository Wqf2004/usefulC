# DFM 业务层介绍

## 业务层的职责

业务层把学生与成绩管理规则封装为 `utility.h` 中的结构体、结果码和函数。调用者通过结构化参数提交数据，并根据 `UtilityResult` 判断操作结果，不需要在界面代码中重复实现字段校验、成绩计算、查询和文件记录规则。

主要实现分布如下：

- `src/utility.c`：学生和成绩文件读取、字段校验、综合成绩与实得学分计算、排序、课程统计、账号注册及认证。
- `src/utility_query.c`：学生和成绩查询、成绩录入。
- `src/utility_delete.c`：删除学生、同步删除其成绩并保存删除记录。
- `src/grade.c`：成绩等级、综合成绩公式及等级学分折算等计算规则。
- `src/file_op.c`：提供行级文件编辑操作，供业务逻辑复用。
- `tests/utility_test.c`：业务层集成测试；`tests/file_op_delete_test.c`：文件行操作测试。

## 数据与规则

学生记录按空白分隔，字段依次为学号、姓名、性别、宿舍号和手机号；成绩记录依次为学号、课程编号、课程名称、学分、平时成绩、实验成绩、卷面成绩、综合成绩和实得学分。两种文件都可以有首行表头，字段本身不能包含空格。

读取记录时会检查字段数量、字段长度、编号格式、手机号及成绩范围。手机号要求为 11 位数字且以 13 至 19 开头。超过输出数组容量时返回 `UTILITY_CAPACITY_ERROR`；格式错误返回 `UTILITY_FORMAT_ERROR`。

成绩综合分的计算规则为：

- 无实验（实验成绩为 `-1`）：平时成绩占 30%，卷面成绩占 70%。
- 有实验：平时成绩占 15%，实验成绩占 15%，卷面成绩占 70%。

实得学分根据综合成绩折算：90 分及以上按 100% 计，80 至 90 分以下按 80% 计，70 至 80 分以下按 75% 计，60 至 70 分以下按 60% 计，低于 60 分为 0。

## 业务流程

- 查询函数对学号或姓名进行完整字段匹配。姓名匹配到多名学生时返回 `UTILITY_DUPLICATE`；宿舍查询和成绩查询会返回匹配数量，成绩查询还会汇总实得学分。
- 成绩录入先确认学生存在并计算派生字段，再追加成绩记录。学生不存在时返回 `UTILITY_NOT_FOUND`。
- 删除学生前先收集学生记录与全部成绩记录并写入删除日志，然后删除成绩和学生记录。找不到学生、学生编号重复、非法编号及文件错误会分别返回对应结果码。
- 成绩排序支持综合成绩或实得学分的升序、降序；排序值相同的记录保留原相对顺序。课程统计按课程编号汇总综合成绩平均值。
- 注册账号时生成随机盐并派生 PBKDF2-SHA256 摘要，账号文件不保存明文密码。登录成功和失败都会追加日志。

## 运行测试

在仓库根目录的 PowerShell 终端执行以下命令。Windows 环境需要 GCC，并链接系统 BCrypt 库：

```powershell
gcc dfm/src/utility.c dfm/src/utility_query.c dfm/src/utility_delete.c dfm/src/grade.c dfm/src/file_op.c dfm/src/security.c dfm/tests/utility_test.c -Idfm/include -std=c17 -Wall -Wextra -Wpedantic -lbcrypt -o dfm/build/utility_test.exe
if ($LASTEXITCODE -eq 0) { .\dfm\build\utility_test.exe }

gcc dfm/src/file_op.c dfm/tests/file_op_delete_test.c -Idfm/include -std=c17 -Wall -Wextra -Wpedantic -o dfm/build/file_op_delete_test.exe
if ($LASTEXITCODE -eq 0) { .\dfm\build\file_op_delete_test.exe }
```

测试使用 `dfm/build/` 下的临时文本文件，结束时会清理测试数据。业务测试覆盖正常流程以及输入格式、数组容量、重复匹配、缺失记录、排序稳定性和认证结果等边界；文件操作测试检查空文件及末行无换行时的插入、替换和删除行为。
